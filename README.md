- `docs/reflection/` for the RiPPlE capture framework

- `database/schema/` for tables, constraints, triggers, views and routines

- `database/tests/` for assessed tests and additional controls
- `database/queries/` for the six decision-support queries
- `deliverables/final-submission/` for submission-oriented artifacts
- `deliverables/student-pack/` for no-Git student instructions and handoff checklists
- `diagrams/` for Workbench model and ER exports
- `.github/workflows/source-verification.yml` for MySQL 8.4 source verification and generated technical-artifact refresh
