# BISM2207 assessment source index

This folder records the authoritative assessment sources used for project design and audit.

## Source documents supplied by the students

1. `要求.pdf`
   - Main BISM2207 System Development assessment specification.
   - Contains project checkpoints, selected-perspective requirements, Tasks 1 to 8/10, final submission format, MySQL/Workbench requirements, SQL query requirements, video requirements, GenAI reflection requirements and FAQs.

2. `BISM2207 rubric.pdf`
   - Marking rubric for the 100-point assessment.
   - High Distinction band is 85 to 100 percent.
   - Used as the quality standard for planning, design justification, stakeholder/community requirements, ER modelling, logical design/data dictionary, data quality, SQL decision support, reflection, video demonstration and communication impact.

3. `case.pdf`
   - Wine Company Case.
   - Authoritative business narrative for personnel, vineyards, grape varieties, wine/products/bottles, suppliers/procurement, customers, addresses and stated scope exclusions.
   - Database requirements and assessed business-rule claims must remain traceable to this case unless clearly labelled as an assumption or perspective-specific extension.

4. `AI Reflection component RiPPlE.pdf`
   - Separate RiPPlE reflection instructions.
   - Covers problem statement, two prompt-progression examples, minimum evaluation/revision requirements and peer-feedback expectations.

## Important handling note

The original PDFs are course materials and are not committed to this public repository by this project automation. Before copying the original PDFs into Git, confirm that redistribution is permitted or make the repository private.

For independent audit, use `AUDIT_STANDARD.md` in this folder as the structured requirement map, then compare implementation claims to the project artifacts and, where available, the original four PDFs supplied directly by the students.

## Source precedence

When sources conflict, do not silently choose one. Record the conflict and request tutor clarification where it can affect marking. Known conflicts are listed in `AUDIT_STANDARD.md` and `docs/requirements/tutor-confirmations.md`.
